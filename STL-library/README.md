# DuoTouch STL Library

This directory contains printable models and reference materials for example DuoTouch attachments.

Files marked `conductive` are intended for conductive parts. Files marked `non-conductive` are intended for structural or insulating parts. PCB dimension sheets are provided as RTF documents where applicable.

# DuoTouch

This repository contains the design resources accompanying **DuoTouch: Passive Two-Footprint Attachments Using Binary Sequences to Extend Touch Interaction**.

## Repository contents

| Component | Description |
| --- | --- |
| [DesignTool](DesignTool/) | Xcode project and Swift source for generating DuoTouch electrode and wiring layouts and exporting SVG or DXF files. |
| [STL-library](STL-library/) | Printable 3D models, preview images, and PCB dimension sheets for example DuoTouch attachments. |

No prebuilt macOS application is included. See [DesignTool/README.md](DesignTool/README.md) for build requirements and instructions.
